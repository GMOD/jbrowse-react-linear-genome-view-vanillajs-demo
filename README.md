# JBrowse linear genome view from a script tag

`@jbrowse/react-linear-genome-view2` v5 from a `<script>` tag: no bundler, no JSX, no React root of your
own. `index.html` is the whole demo.

See it running at https://jbrowse.org/demos/lgv-vanillajs/.

## Usage

```bash
npx serve -S .
```

The `@next` tag fetches the newest v5 prerelease. Pin a version for production.

More examples: https://jbrowse.org/storybook/, and the
[embedding guide](https://jbrowse.org/jb2/docs/embedded_components/).
